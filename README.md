# DoneNext

工作管理平台以 Node.js 實作，伺服器本身不依賴任何外部套件。頂層分為三個頁籤：
**1.任務管理**（支援階層式任務結構、拖曳排序、多條件篩選與查詢，適合小型團隊日常追蹤工作進度）
**2.常用工具**（JSON Viewer、Base64 編解碼等常用小工具）
**3.異動說明**（版本異動紀錄），未來可持續擴充新頁籤。

## 功能說明

### 任務列表

開啟網站後預設顯示「進行中」狀態的任務。每筆任務以卡片方式呈現，顯示任務名稱、辦理狀態、優先序、項目類型、負責人、新增時間、預計開始與完成日期。

**篩選**：工具列提供四個篩選條件，可依負責人、辦理狀態、優先序、項目類型組合篩選。狀態篩選僅作用於第一層任務，子任務不受影響，確保子任務始終隨父任務一起顯示。

**排序**：預設為使用者自訂的拖曳順序。點選排序列的按鈕（新增時間、負責人、辦理狀態、預計開始、預計完成）可依該欄位降序排列；再次點選同一按鈕，回到自訂順序。排序僅對第一層任務生效，子任務始終維持自訂順序。

### 階層式任務

任務支援無限層級的父子關係。點選「子任務」按鈕可在任意任務下新增子任務，子任務展開後可再繼續新增下一層。子任務預設摺疊，點選 ▶ 展開，點選 ▼ 收合。

- 新增**根任務**時，預設排在所有任務最上方
- 新增**子任務**時，預設排在同層子任務最上方
- 子任務辦理狀態變更為「已完成」時，自動移動到同層子任務最下方
- 刪除父任務時，其所有子任務（含子子任務）一併刪除

### 拖曳排序

每筆任務左側有拖曳把手（⠿），按住後可自由移動：

- **放到任務之間的藍色指示線**：該任務移動到此位置，成為同層的平行任務。可跨層移動，例如將子任務拖曳到根層，或將根任務拖曳到其他任務的子任務位置
- **放到任務本體（藍框高亮）**：該任務成為目標任務的最後一個子任務

系統會自動防止將任務拖曳到自身或其子孫任務之下，避免產生循環結構。

### 複製任務

每筆任務提供「複製」按鈕，點選後會完整複製該任務及其所有子任務（含子子任務），複製結果預設排在清單最後，可再以拖曳調整位置。

### 查詢歷史

切換至「查詢歷史」頁籤，可跨多個條件同時搜尋：

- 任務名稱（模糊比對）
- 負責人（模糊比對）
- 辦理狀態
- 新增時間區間（起訖日期）
- 預計開始日期區間
- 預計完成日期區間

查詢結果顯示符合條件的所有任務（包含子任務），點選「編輯」可直接修改。

### 管理作業

切換至「管理作業」頁籤，可維護以下兩份清單：

**負責人管理**：新增或移除負責人姓名。清單中的人員會出現在新增任務表單的自動完成建議與篩選下拉選單中。

**項目類型管理**：新增或移除項目類型（預設：專案需求、系統維運、注意事項）。清單中的類型會同步更新到新增任務表單與篩選下拉選單。

### 常用工具

切換至頂層「常用工具」頁籤，提供與任務資料無關的通用小工具：

**JSON Viewer**：貼上 JSON 內容後即時解析，以樹狀結構呈現階層，可點選 + / − 展開或收合每個節點；輸入格式錯誤時於欄位下方顯示錯誤訊息與位置。

**Base64 編解碼**：於左右兩個文字框輸入文字或 Base64 字串，按「編碼為 Base64」或「解碼為文字」轉換，正確處理中文等多位元組 UTF-8 字元；輸入不合法時顯示行內錯誤訊息。

## 任務欄位

| 欄位 | 說明 |
|------|------|
| 任務項目 | 任務名稱（必填） |
| 負責人 | 從管理清單選擇或手動輸入 |
| 新增時間 | 日期由使用者選擇；時間由系統在儲存時自動記錄，用於同日任務的排序 |
| 預計開始日期 | 選填 |
| 預計完成日期 | 選填 |
| 辦理狀態 | 進行中 / 已完成 |
| 優先序 | 高 / 中 / 低（僅第一層任務顯示） |
| 項目類型 | 從管理清單維護（僅第一層任務顯示） |
| 任務說明 | 選填備註，顯示於任務名稱下方 |

## 啟動方式

```bash
# 預設 port 3000
node server.js
or
npm start

# 指定 port
node server.js 8080
```

瀏覽器開啟 `http://localhost:3000`

## 系統需求

- Node.js 18+
- 直接執行 `node server.js` 即可啟動，無需 `npm install`
- 若需安裝 Windows 服務，則須先執行 `npm install`（安裝 node-windows）

## 設為 Windows 服務（開機自動啟動）

使用 [node-windows](https://github.com/coreybutler/node-windows) 將應用程式註冊為正式的 Windows 服務，安裝後可在 `services.msc` 中查看與管理。

### 首次設定（只需執行一次）

```bash
npm install
```

### 安裝服務

以**系統管理員**身份開啟命令提示字元或 PowerShell，執行：

```bash
npm run installService
```

安裝後：
- `services.msc` 中可看到 **DoneNextService**
- 啟動類型為「自動」，開機即啟動，無需登入
- 異常中止時自動重試

### 移除服務

以**系統管理員**身份執行：

```bash
npm run uninstallService
```

## 資料儲存

所有資料以 JSON 檔案儲存，無需資料庫。`data/` 與 `logs/` 目錄不存在時會自動建立。

| 檔案 | 內容 |
|------|------|
| `data/todos.json` | 任務資料（含所有欄位與父子關係） |
| `data/users.json` | 負責人清單 |
| `data/types.json` | 項目類型清單 |
| `logs/YYYY-MM-DD.log` | 每日操作日誌，記錄所有 API 呼叫（自動建立） |
